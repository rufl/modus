# Security Policy

> **Documentation status: maintained reference.** This file defines the current private vulnerability-reporting boundary.

MODUS is pre-release software. Only the current `0.9.x` development line receives security fixes.

Report suspected vulnerabilities privately through the repository host's security-advisory channel or directly to the project maintainer. Do not include secrets, credentials, or exploit details in public issues.

Include the affected build, reproduction steps, impact, and any relevant logs. No response-time or bounty commitment is currently offered.
